================================================================================
           DPAD ARCADE GAME HUB - COMPREHENSIVE SOUND EFFECTS SPECIFICATION
================================================================================

Document Purpose:
This document details the complete sound effect (SFX) specifications for all 30 games 
in the Dpad Arcade Game Hub. It covers universal game lifecycle sounds (Game Start, 
Game Pause, Game Resume, Game End - Win/Lose) as well as specific gameplay event SFX.
It also outlines a sound reuse framework across games to ensure audio consistency, 
lightweight footprint, and efficient memory usage.

--------------------------------------------------------------------------------
PART 1: GLOBAL REUSABLE SOUND LIBRARY MATRIX
--------------------------------------------------------------------------------

To minimize asset bloat and maintain a cohesive arcade aesthetic, sound effects are 
categorized into Shared Core SFX (reused across multiple games) and Game-Specific SFX.

SHARED CORE SFX REGISTRY:
1.  SFX_GAME_START        : Upward 3-note ascending chime (C4-E4-G4) - Signals round/game start.
2.  SFX_GAME_PAUSE        : Soft double low-tone blip (E4-C4) - Triggered when pause overlay opens.
3.  SFX_GAME_RESUME       : Quick bright single tone (G4) - Triggered when resuming play.
4.  SFX_GAME_OVER_WIN     : Victory fanfare / 4-note ascending triumph sequence.
5.  SFX_GAME_OVER_LOSE    : Downward 3-note descending sad tone / low thud.
6.  SFX_UI_CLICK          : Short crisp click/tick - Menu navigation, button presses.
7.  SFX_UI_ERROR          : Low double buzz - Invalid moves, locked options, wrong input.
8.  SFX_SCORE_POINT       : High-pitched coin/ping - Small score gains, eating items, simple points.
9.  SFX_HIGH_SCORE        : Sparkling ascending chime - Breaking a high score record.
10. SFX_EXPLOSION         : Deep noise rumble / explosion burst - Destruction, bomb detonation, crashes.
11. SFX_JUMP              : Quick pitch slide upward - Character jumping or leaping.
12. SFX_SWOOSH            : Fast air movement / slide sound - Fast movement, dash, or card drag.
13. SFX_TILE_SELECT       : Soft wooden/plastic click - Selecting grid cells, cards, or puzzle pieces.
14. SFX_TILE_PLACE        : Firm snap / click - Dropping pieces, placing cards, locking tetrominos.
15. SFX_MATCH_SUCCESS     : Harmonic twin-chime - Clearing lines, matching pairs, solving equations.
16. SFX_POWERUP           : Bright ascending arpeggio - Collecting special items or buff activations.
17. SFX_HAZARD_HIT        : Sharp punch / slap - Taking damage, losing a life, hitting wall.

--------------------------------------------------------------------------------
PART 3: IMPLEMENTATION & REUSE GUIDELINES FOR SOUNDMANAGER
--------------------------------------------------------------------------------

1. Centralized Event Dispatching:
   All activities inheriting from BaseGameActivity receive standard lifecycle SFX 
   calls automatically in:
   - startGameWithAnalytics() -> SoundManager.playGameStart()
   - showGameGuide() / onPause() -> SoundManager.playGamePause()
   - resume() / dismiss guide  -> SoundManager.playGameResume()
   - gameView.onGameOver       -> SoundManager.playGameOver(isWin)

2. Pitch Shifting / Dynamic Synthesis Strategy:
   To keep app size lightweight under 15MB:
   - Use ToneGenerator / SoundPool with frequency modulation for variable SFX 
     (e.g., 2048 tile pitch ramping, Simon Says notes, Simon pad tones).
   - Reuse core PCM samples across similar genres (e.g., StarFighter laser used in 
     BrickBreak laser powerup; Explosion sample shared across Tanks, Fruit Slicer, 
     Dungeon, and StarFighter).
